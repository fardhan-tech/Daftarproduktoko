# Aplikasi Daftar Produk Toko

Aplikasi Daftar Produk Toko merupakan aplikasi desktop berbasis **JavaFX** yang dibuat dengan memodifikasi proyek hasil praktikum sebelumnya. Aplikasi ini digunakan untuk mengelola dan menampilkan data produk toko dengan menerapkan konsep Object-Oriented Programming (OOP).

Proyek ini dikembangkan menggunakan Java dan JavaFX dengan mempertahankan struktur package, pola navigasi, serta desain antarmuka dari proyek praktikum.

## Fitur Aplikasi

Aplikasi ini memiliki beberapa fitur utama:

1. **Tambah Produk**
   - Menambahkan produk baru ke dalam daftar.
   - Mengisi nama produk, kategori, dan harga.
   - Kode produk dibuat secara otomatis.

2. **Daftar Produk**
   - Menampilkan seluruh produk dalam bentuk tabel.
   - Menampilkan kode, nama, kategori, dan harga produk.
   - Harga ditampilkan dalam format Rupiah.

3. **Pencarian Produk**
   - Mencari produk berdasarkan nama.
   - Menampilkan hasil pencarian sesuai kata kunci.

4. **Detail Produk**
   - Menampilkan informasi lengkap produk yang dipilih.
   - Menampilkan kode, nama, kategori, dan harga produk.

5. **Validasi Input**
   - Nama produk tidak boleh kosong.
   - Kategori wajib dipilih.
   - Harga harus berupa angka.
   - Harga harus lebih dari nol.

## Teknologi yang Digunakan

- **Bahasa Pemrograman:** Java
- **Framework GUI:** JavaFX
- **FXML:** Mendesain antarmuka aplikasi.
- **CSS:** Mengatur tampilan dan desain aplikasi.
- **IDE:** Apache NetBeans
- **JavaFX Scene Builder:** Membantu perancangan tampilan antarmuka.



## Cara Menjalankan Aplikasi

Berikut langkah-langkah untuk menjalankan aplikasi:

1. Pastikan Java Development Kit (JDK) dan JavaFX sudah terpasang dan dikonfigurasi.
2. Download atau clone repository ini.
3. Buka aplikasi Apache NetBeans.
4. Pilih **File → Open Project**.
5. Pilih folder proyek yang sudah diunduh.
6. Pastikan konfigurasi JavaFX sudah sesuai dengan versi yang digunakan.
7. Buka file `MainApp.java`.
8. Jalankan aplikasi dengan menekan tombol **Run Project (F6)**.
